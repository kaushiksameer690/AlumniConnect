# AlumniConnect – Alumni Mentorship Booking Platform

##  Overview

AlumniConnect is a responsive front-end web application that connects students with alumni mentors. It allows students to explore mentor profiles, book mentorship sessions, participate in community discussions, and manage their bookings through a simple and user-friendly interface.

This project is built using **HTML, CSS, and JavaScript** and uses the browser's **Local Storage** to simulate data persistence without requiring a backend.

---

##  Features

*  Responsive Home Page
*  Browse Alumni Mentors
*  Book Mentorship Sessions
*  View and Manage Bookings
*  Community Discussion Forum
*  User Dashboard
*  Local Storage for data persistence
*  Responsive design for desktop, tablet, and mobile devices

##  Getting Started

1. Clone the repository.

```
git clone <repository-url>
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

No installation or additional dependencies are required.

---

##  How It Works

* Students can browse available mentors.
* Selecting **Book** on a mentor automatically opens the booking page with that mentor selected.
* Users can also create a booking directly from the Bookings page by selecting a mentor from the dropdown.
* Submitted bookings are stored in the browser using Local Storage.
* Users can participate in forum discussions, which are also stored locally.
* The dashboard displays booking information and updates automatically.
